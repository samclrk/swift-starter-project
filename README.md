# KanbanBoard

A minimal macOS Kanban app written in SwiftUI. The goal is to provide a native Apple look and feel with just the basic features needed to manage tasks.

## Features

- Organise tasks in columns (Todo, In Progress and Done by default).
- Add tasks by typing in the column footer.
- Drag to reorder tasks within a column (coming soon).
- SwiftUI interface designed for macOS.

## Requirements

- macOS 12+
- Xcode 15 or later

## Getting Started

Open the project in Xcode and run the **KanbanBoard** target. You can edit the columns and tasks in `KanbanBoard/Models` and modify the views in `KanbanBoard/Views`.

## Project Structure

```
KanbanBoard/
├── KanbanBoardApp.swift     // App entry point
├── Models/                  // Task and column models
├── Views/                   // SwiftUI views
```

Feel free to expand on this foundation to suit your needs.
